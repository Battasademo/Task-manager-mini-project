# Task Manager

A simple task manager built with HTML, CSS and vanilla JavaScript.

## Features
- Add, complete and delete tasks
- Live counters for total and completed tasks
- Tasks are saved in the browser (`localStorage`), so they stay after a refresh
- Responsive layout (works on mobile)

## Run it
Open `index.html` in your browser. No install needed.

## What I practiced
- DOM manipulation and event handling
- Event delegation
- `localStorage` with `JSON.parse` / `JSON.stringify`
- Safe rendering of user input with `textContent`
- Flexbox, CSS variables and media queries
